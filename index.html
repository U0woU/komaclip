🗺️ KomaClip おおまかな理想図（構成＆ワークフロー）

10秒に1枚撮影 → 離席カット・右下GIF合成・軽い色調調整 → ローカルMP4出力までの全体像

🎯 目指す使い心地

アプリを開いてすぐ録画開始でき、終わった直後に「離席をサッと消して、右下に推しGIFやスタンプをポンと載せて、10秒でMP4書き出し」できる軽快さ。

⚡ 1時間勉強の目安

10秒に1枚 ＝ 360枚。15fpsで書き出すとちょうど 24秒 のSNS・YouTubeショートにもぴったりなテンポの良い勉強タイムラプスになります。

🛠️ 今後の拡張アイデア

BGM（ロフィ音源）の合成、複数セッションの結合、SNS向け縦横自動リサイズなどへ拡張しやすいファイル分割構成になっています。

⚙️ ストレージ管理

撮影したフレームは1枚ごとにブラウザ内の IndexedDB へ自動保存されます。ブラウザを閉じても次回起動時に復元できます。

ℹ️ KomaClip について
  • 100% ローカル処理：映像や画像はサーバーへ一切送信されません。
  • バックグラウンド対策：Web Worker タイマー＋PiPにより、別タブ作業中でも撮影間隔のズレを防ぎます。
  • プレビュー完全一致：編集画面で調整した右下GIF・色調・回転・タイマー・文字がそのままMP4へ書き出されます。
  • ショートカット（編集）：← → コマ移動、Space 再生/停止、Delete / Backspace 除外・復元。
