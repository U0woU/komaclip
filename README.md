# KomaClip — 勉強タイムラプス

https://u0wou.github.io/komaclip/

10秒に1枚自動で撮影し、離席カット・右下GIF合成・軽い色調調整を行ってローカルでMP4出力できるWebアプリです。

## 主な機能
- **録画（10秒に1枚・規定）**: Web Worker タイマー＋PiP＋省電力モード＋IndexedDB自動保存
- **軽い編集（WYSIWYG）**:
  - コマ一覧グリッドでのなぞり除外・前後一括カット・離席（静止）自動検出・2倍速間引き
  - **右下GIFアニメ / 内蔵ミニスタンプ合成**（配置・サイズ%・不透明度・余白をリアルタイム調整）
  - **色調・回転**（明るさ・コントラスト・彩度・プリセット・90°回転・左右反転）
  - **文字・タイマー焼き込み**（勉強経過時間＆メモ透かし）
- **理想図タブ (`🗺️`)**: `index.html` 内のコメント＆画面タブに全体構成図を内蔵
- **MP4書き出し**: WebCodecs (`VideoEncoder` + `mp4-muxer`) による高速ローカル生成＋自動フォールバック

## ローカル起動方法
ES Module（`type="module"`）を使用しているため、`index.html` の直接ダブルクリックではなく簡易サーバー経由で開いてください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```
