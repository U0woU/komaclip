# KomaClip (ver.1.0.0) — 省電力・間欠タイムラプス撮影ツール

https://u0wou.github.io/komaclip/

複数カメラのデバイスID選択、必要な瞬間だけカメラを起動して即停止する間欠駆動、静止（離席）コマの自動破棄、WebM書き出しに特化した軽量・モノクロUI版です。

## 主な特徴
- **バージョン確認（`ver.1.0.0`）**: 右上の「設定」ボタンからバージョンや露出安定待ち時間・ストレージ消去を確認・操作できます。
- **10〜40秒ランダム撮影間隔**: 撮影間隔に「ランダム（10〜40秒）」を追加し、毎コマ10秒以上40秒以下のランダムな間隔で撮影できます（固定間隔 5/10/15/20/30秒も選択可能）。
- **さらなる軽量化**: IndexedDB保存時にRAM上の画像Blobを解放し、WebM書き出し時は1コマずつ読み出す方式に変更。1秒間隔のWorkerタイマーと軽量な輝度差分計算（48×27）で長時間撮影時の負荷を抑えています。
- **シンプルなモノクロUI**: 左側の折りたたみサイドバーを廃止し、撮影・設定確認に集中できるモノクロのダーク／ライトテーマに統一しました。
- **複数カメラ切替・発熱対策・WebM出力**: `deviceId` ベースのカメラ切替、撮影ごとの `track.stop()`、静止自動破棄、省電力オーバーレイ、WebM（VP9/VP8）書き出しに対応。

## ローカル起動方法
```bash
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```
