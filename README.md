# KomaClip — 発熱防止・間欠タイムラプス撮影ツール

https://u0wou.github.io/komaclip/

ブラウザ内編集やMP4エンコードを廃止し、**「カメラを必要な瞬間だけ起動して即停止する間欠撮影」＋「静止（離席）コマの自動破棄」＋「編集ソフト向けWebM出力」**に特化した軽量バージョンです。

## 主な特徴
- **カメラ発熱対策（間欠駆動）**: 撮影間隔ごとに `getUserMedia()` でカメラを起動 → 露出安定後に1枚撮影 → 即座に `track.stop()` でカメラを物理停止します。
- **編集機能・MP4出力の全削除**: カット編集・右下GIF・色調補正・`mp4-muxer`・PiPを削除し、外部編集ソフトへそのまま渡せる **WebM書き出し** に一本化しました。
- **静止（離席）画像の自動検知＆即破棄**: 前回採用した画像と輝度差分を比較し、動きがない画像は保存せずその場で破棄します。

## ローカル起動方法
ES Module（`type="module"`）を使用しているため、簡易サーバー経由で開いてください。

```bash
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```
