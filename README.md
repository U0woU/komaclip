# KomaClip — 発熱防止・間欠タイムラプス撮影ツール

https://u0wou.github.io/komaclip/

ブラウザ内編集やMP4エンコードを廃止し、**「複数カメラのデバイスID選択」＋「必要な瞬間だけカメラ起動＆即停止の間欠撮影」＋「静止（離席）コマの自動破棄」＋「編集ソフト向けWebM出力」**に特化した軽量バージョンです。

## 主な特徴
- **複数カメラ切替（PC/USBカメラ対応）**: `facingMode` ではなく `enumerateDevices()` の `deviceId` を使用し、ドロップダウン選択＆「次のカメラへ」ボタンで確実に切替可能。選択カメラは記憶されます。
- **カメラ発熱対策（間欠駆動）**: 撮影間隔ごとに `getUserMedia()` でカメラを起動 → 露出安定後に1枚撮影 → 即座に `track.stop()` でカメラを物理停止します。
- **静止（離席）画像の自動検知＆即破棄**: 前回採用した画像と輝度差分を比較し、動きがない画像は保存せずその場で破棄します。
- **WebM書き出し**: 外部編集ソフトへそのまま渡せる WebM（VP9/VP8）を出力します。

## ローカル起動方法
```bash
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```
